# Security and sensitive-data reports

This repository is a bounded research artifact, not the GÖZCÜ EDGE product.

If you find a credential, personal or vessel data, private product material,
an executable attack path outside the documented lab boundary, or another
sensitive-data exposure, do not open a public issue. Email
`info@nauticmall.com` with the affected path and a minimal description.

Ordinary reproducibility failures, documentation errors, and scientific
questions may be reported through public GitHub issues.
